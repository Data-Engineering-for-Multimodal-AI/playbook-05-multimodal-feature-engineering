# Data licenses

This file lists the datasets and models this playbook uses, where they come from, and their licenses. The code in this repository is MIT-licensed. That license does not cover third-party data or models; each one keeps its own license, listed below.

## Datasets

| Dataset | Source | License | In this repo |
|---|---|---|---|
| Waymo Open Motion Dataset (WOMD) v1.3.1, `tf_example` format | [waymo.com/open](https://waymo.com/open/), `gs://waymo_open_dataset_motion_v_1_3_1/`. Registration required | [Waymo Dataset License Agreement for Non-Commercial Use](https://waymo.com/open/terms/) | No. Downloaded by `make data` (`bash scripts/fetch_data.sh`) into `data/motion/`: 10 of 150 validation_interactive shards (about 5 GB) and one training shard (1.1 GB) by default |
| WOMD-Reasoning (language Q&As about WOMD scenarios) | [waymo.com/open](https://waymo.com/open/), `gs://waymo_open_dataset_womd_reasoning/` ([code](https://github.com/yhli123/WOMD-Reasoning)) | The Waymo terms above, plus its own `LICENSE` (UC Regents; educational, research and not-for-profit use) | No. Downloaded by the same script into `data/reasoning/` (about 1 GB unpacked), with its `LICENSE` file |
| Synthetic data in the Waymo formats | Generated by `tests/make_fixture.py` | MIT (this repository) | No. Written to `synthetic/` by `make run` when there is no Waymo data in `data/`, and by `make smoke` |

## Models

| Model | Source | License | How it's used |
|---|---|---|---|
| all-mpnet-base-v2 | [sentence-transformers/all-mpnet-base-v2](https://huggingface.co/sentence-transformers/all-mpnet-base-v2) | Apache-2.0 | Embeds the WOMD-Reasoning Q&As (768 dimensions). Downloaded from Hugging Face on first use |
| paraphrase-MiniLM-L6-v2 | [sentence-transformers/paraphrase-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/paraphrase-MiniLM-L6-v2) | Apache-2.0 | Fallback in `waymo_feature_pipeline.py` if all-mpnet-base-v2 fails to load |

## Notes

- The Waymo data is for non-commercial use. The Waymo license and the WOMD-Reasoning license, not this repository's MIT license, govern use of the data. The README says features derived from the data are covered too.
- The Waymo terms allow sharing the data only with registered users. `data/motion/` and `data/reasoning/` are in `.gitignore`; don't commit them.
- From `data/README.md`: "This playbook was made using the Waymo Open Dataset, provided by Waymo LLC under the Waymo Dataset License Agreement for Non-Commercial Use, available at waymo.com/open/terms, and your access and use of such work are governed by the terms and conditions therein."
