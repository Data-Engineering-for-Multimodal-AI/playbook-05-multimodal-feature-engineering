# Figures from the first-edition run

These charts were produced by the scripts as they were at the `first-edition` tag. They are kept as illustrations only. The scripts now write their charts to `outputs/`, which git ignores.

`feature_importance.png` and `text_embedding_umap.png` come from the first-edition yield model. That model's labels and features had problems that were fixed in the 2026 update (see the main README, "Differences from the printed book"), so don't read results from these two charts.
