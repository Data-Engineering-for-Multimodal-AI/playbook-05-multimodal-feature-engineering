# Outputs Directory

This directory stores all outputs generated by the multimodal feature engineering pipeline. The outputs are organized into subdirectories based on their type and purpose.

## Directory Structure

```
outputs/
├── validation_analysis/     # Results from dataset analysis
│   ├── scenario_id_comparison.json
│   ├── question_distribution.json
│   ├── interaction_patterns.json
│   └── visualizations/
│       ├── question_distribution.png
│       └── ...
│
├── combined_features/       # Features from combined pipeline
│   ├── combined_features.csv
│   └── visualizations/
│       ├── agent_distributions.png
│       └── ...
│
└── multimodal_features/     # Multimodal features and model outputs
    ├── fused_features.csv
    ├── yield_model_results.json
    └── visualizations/
        ├── text_embedding_umap.png
        ├── feature_importance.png
        └── ...
```

## Output Types

### Validation Analysis

Contains analysis results from data inspection and validation:
- Scenario ID comparisons between datasets
- Question type distributions
- Interaction pattern frequencies
- Visualizations of dataset characteristics

### Combined Features

Contains outputs from the combined feature pipeline:
- Combined features from motion and reasoning datasets
- Statistics on common scenarios
- Visualizations of combined features

### Multimodal Features

Contains outputs from the multimodal feature pipeline:
- Fused feature vectors combining motion and text
- Text embeddings for reasoning data
- Yield prediction model results
- Feature importance analyses
- Performance metrics

## Note

Some large output files (like CSVs with features for many scenarios) may be excluded from version control via .gitignore. These files will be generated when you run the pipeline scripts.
